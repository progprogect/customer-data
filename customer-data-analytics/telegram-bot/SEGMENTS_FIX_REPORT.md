# 🔧 Исправление отображения сегментов

**Дата:** 21 сентября 2025  
**Статус:** ✅ ИСПРАВЛЕНО  
**Проблема:** Отображение "N/A" и "0" вместо реальных данных сегментов

## 🐛 Описание проблемы

При выборе "Сегменты → Снапшот" в боте отображались:

```
📊 Распределение сегментов
Кластер  | Пользователи | Доля    
────────────────────────────────
N/A      | 0            | 1.8%    
N/A      | 0            | 55.1%   
N/A      | 0            | 43.2%
```

Вместо правильных данных:

```
📊 Распределение сегментов
Кластер  | Пользователи | Доля    
────────────────────────────────
Низкий   | 53           | 1.8%    
Средний  | 1 646        | 55.1%   
Высокий  | 1 291        | 43.2%
```

## 🔍 Причина проблемы

Проблема была в функции `format_segments_table()` в файле `utils/formatters.py`. Форматтер искал данные по неправильным ключам:

**❌ Неправильно (старый код):**
```python
users = segment.get("users", segment.get("user_count", segment.get("count", segment.get("users_count", 0))))
```

**✅ Правильно (исправленный код):**
```python
users = segment.get("users_count", segment.get("users", segment.get("user_count", segment.get("count", 0))))
```

## 🛠️ Исправление

### 1. Исправлен порядок поиска ключей в `format_segments_table()`

**Файл:** `utils/formatters.py`  
**Строка:** 186

```python
# БЫЛО:
users = segment.get("users", segment.get("user_count", segment.get("count", segment.get("users_count", 0))))

# СТАЛО:
users = segment.get("users_count", segment.get("users", segment.get("user_count", segment.get("count", 0))))
```

### 2. Структура данных API

API возвращает данные в формате:
```json
{
  "segments": [
    {
      "cluster_id": 0,
      "users_count": 53,
      "share": 0.017725752508361205
    }
  ]
}
```

Ключи: `cluster_id`, `users_count`, `share`
