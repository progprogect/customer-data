## 📊 **Реализованная логика:**

### **Эвристика вероятности покупки:**
```python
# Высокая частота + низкая давность = высокая вероятность покупки
frequency_score = min(frequency / 10.0, 1.0)  # 0-1
recency_score = max(0, (90 - recency) / 90.0)  # 0-1
probability = (frequency_score * 0.6 + recency_score * 0.4)
```

### **Используемые реальные фичи:**
- `frequency_90d` - количество покупок за 90 дней
- `recency_days` - дни с последней покупки
- `aov_180d` - средний чек за 180 дней
- `monetary_180d` - общая сумма за 180 дней
- `orders_lifetime` - общее количество заказов
- `revenue_lifetime` - общая выручка
- `categories_unique` - количество уникальных категорий
