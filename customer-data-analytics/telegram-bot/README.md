# 🤖 Telegram Marketing Assistant

Карманный дашборд для маркетинга с быстрым доступом к ключевым метрикам прямо в Telegram.

## 🚀 Возможности

- **👥 Сегментация** - анализ кластеров пользователей с динамикой и миграциями
- **🛒 Вероятность покупки** - топ клиентов с высоким потенциалом (30 дней)
- **⚠️ Риск оттока** - анализ клиентов на грани ухода (60 дней)
- **🎯 Рекомендации** - персонализированные предложения товаров
- **🚨 Аномалии** - необычные паттерны поведения пользователей
- **💰 Эластичность цен** - анализ чувствительности к ценам по категориям
- **🔎 Поиск пользователя** - детальная сводка по ID пользователя

## 📱 Команды бота

- `/start` - главное меню
- `/help` - справка по командам
- `/user <ID>` - быстрая сводка пользователя
- `/today` - ключевые цифры за сегодня

## 🛠️ Установка и запуск

### 1. Предварительные требования

- Python 3.8+
- Telegram Bot Token (получить у @BotFather)
- Запущенный Customer Data Analytics API (localhost:8000)

### 2. Установка зависимостей

```bash
cd telegram-bot
python3 -m venv venv
source venv/bin/activate  # Linux/Mac
# или venv\Scripts\activate  # Windows
pip install -r requirements.txt
```

### 3. Настройка конфигурации

Создайте файл `.env` в корне проекта:

```env
# Telegram Bot
BOT_TOKEN=your_bot_token_here

# API
API_URL=http://localhost:8000
API_KEY=  # Опционально

# Database
DATABASE_URL=postgresql://username:password@localhost:5432/customer_data

# Bot Settings
RATE_LIMIT_SECONDS=2
PAGE_SIZE=10

# Default Thresholds
DEFAULT_PROBABILITY_THRESHOLD=0.7
DEFAULT_CHURN_THRESHOLD=0.6

# Logging
LOG_LEVEL=INFO
LOG_FILE=logs/marketing_bot.log
```

### 4. Запуск бота

```bash
source venv/bin/activate
python main.py
```

### 5. Тестирование

```bash
source venv/bin/activate
python test_integration.py
```

### API Integration

Бот интегрируется с существующими API endpoints:

- **LTV**: `/api/v1/ltv/summary`, `/api/v1/ltv/users`
- **Segments**: `/api/v1/segments/distribution`
- **ML**: `/api/v1/ml/purchase-probability`, `/api/v1/ml/churn-prediction`
- **Recommendations**: `/api/v1/reco/user-hybrid`
- **Anomalies**: `/api/v1/anomalies/weekly`
- **Users**: `/api/v1/users/{id}/ltv`, `/api/v1/users/{id}/events`

## 🔧 Особенности

### Rate Limiting

- 1 запрос в секунду на пользователя
- Автоматическое ожидание при превышении лимита
- Защита от спама API запросов

### Форматирование

- HTML форматирование для лучшей читаемости
- Компактные таблицы для мобильных устройств
- Эмодзи для визуального разделения
- Автоматическое обрезание длинных сообщений

### Обработка ошибок

- Дружелюбные сообщения об ошибках
- Graceful fallback при недоступности API
- Логирование всех операций
- Retry механизм для временных сбоев
